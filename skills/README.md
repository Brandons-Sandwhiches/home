# skills

One folder per skill under a bucket: `skills/<bucket>/<skill>/`. Each bucket README lists its skills. Layout rules: [AGENTS.md](../AGENTS.md#rules). A skill stays here only while it beats "no skill" on the evals ([evals](../evals/README.md)).

- [knowledge](knowledge/README.md): the wiki, and learning from corrections.
- [productivity](productivity/README.md): discovery interview.
- [review](review/README.md): agent-review and ECRS review.
