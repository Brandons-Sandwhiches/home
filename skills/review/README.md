# review

Skills that critique work and return changes, without applying them.

## Model-invoked

- [agent-review](agent-review/SKILL.md): three-level evidence review. Level 1 (a separate agent checks a named artifact) is the default quick check. Vendored from [captivus/agent-review](https://github.com/captivus/agent-review) v1.0.0 (MIT). Local changes: `effort: high` removed, one em-dash replaced.
- [ecrs-review](ecrs-review/SKILL.md): Eliminate, Combine, Rearrange, Simplify; the cut pass on code and rule PRs before merge.
